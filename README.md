#Sistema de Evaluación Nutricional Infantil en Ecuador

Descripción del proyecto
Este proyecto consiste en el desarrollo de un programa orientado a la evaluación del estado nutricional de niños en Ecuador, utilizando cálculos estadísticos basados en la desviación estándar (DE) y valores de referencia establecidos por la Organización Mundial de la Salud (OMS) para la evaluación del crecimiento y desarrollo infantil.

El sistema permite analizar diferentes indicadores antropométricos, como peso, talla y edad, con el objetivo de determinar si los valores registrados se encuentran dentro de los rangos esperados para la población infantil. Mediante el cálculo de la desviación estándar y la comparación con los patrones de crecimiento de la OMS, es posible identificar posibles casos de desnutrición, crecimiento adecuado o alteraciones en el desarrollo físico.

Además de evaluar individualmente los datos nutricionales, el proyecto busca realizar un análisis geográfico y estadístico de Ecuador, permitiendo identificar las zonas con mayor incidencia de desnutrición infantil. La información puede ser agrupada y analizada por ciudad, provincia o zona geográfica, con el propósito de determinar cuáles presentan los mayores índices de desnutrición.
